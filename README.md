# Devbord for Mac and Windows

The desktop app of [Devbord](https://devbord.com): kanban boards, error tracking and time tracking for dev teams, in a window of its own.

## Download

Get the latest version from [Releases](https://github.com/devbord-com/desktop/releases/latest):

- **Mac:** `Devbord_<version>_universal.dmg` (Apple silicon and Intel)
- **Windows:** `Devbord_<version>_x64-setup.exe`

The app updates itself: when a new version is out, it asks whether to install it.
